# Input Data and Results

This folder contains datasets of input feature maps, weights, and configuration files used for testing the FastConv architecture. These data packages are generated by the `fast-conv` utility and serve as input stimuli for functional simulations and verification.

Each dataset subfolder includes:

- Input feature maps and kernel weights in SystemVerilog format (`data.sv`), organized by channels and windows.
- Auxiliary configuration files specifying sizes, quantization parameters, and other metadata to guide the RTL testbench.
- Optional output result datasets for comparison to simulation outputs to verify correctness.

Use these data files to:

- Drive functional simulations of the FastConv RTL modules.
- Validate different convolution kernel sizes, channel configurations, and quantization setups.
- Benchmark accuracy and performance against expected output results.

Datasets are named according to their project or configuration and can be extended or replaced by generating new sets with the `fast-conv` CLI tool.
