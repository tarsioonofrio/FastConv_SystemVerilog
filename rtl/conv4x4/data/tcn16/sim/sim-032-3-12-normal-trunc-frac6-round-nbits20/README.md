# TCN16 Cin=3, Cout=12 frac6 rounded dataset

Canonical workload: 32x32 input, Cin=3, Cout=12, 3x3 kernel, seed=0, NBITS=20 and QUANT_BITS=8. The scale-576 transformed weights retain six fractional bits with nearest rounding.

This package is intended for the matching TCN16 pretransformed-frac6 RTL with product rounding. `generation.json` records the source revision and package hash.

Library-reported R2: 0.9997313900755722.
