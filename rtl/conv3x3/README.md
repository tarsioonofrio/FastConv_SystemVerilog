# FastConv 3x3 architectures

This directory contains the 3x3 IFN9 and TCN9 RTL variants, their generated
data and algorithm support files, and the shared streaming-column testbench.
Each top-level source declares `Conv`; compile one selected source per build.

## Current top-level RTL candidates

The source files at this directory's root are selectable candidates, not a
claim that every file has completed synthesis or power analysis. The current
inventory is generated by `make audit-layout`, which also shows which active
ASIC manifests reference each root-level source.

The main families are:

- IFN9: 6, 12, and 18 MACs; the 18-MAC family has rowconst and pretransformed
  variants.
- TCN9: 5 MACs; rowconst, pretransformed, and pretransformed-frac6 candidates.

Retired RTL and historical flow evidence live under `archive/`. Do not infer
that an RTL is retired solely because its synthesis data is absent, or that a
flow is current solely because its directory exists. The selected source and
workload are recorded in each synthesis configuration's `list-file.txt`.

## Functional simulation

For a streaming-column RTL, select the algorithm, MAC count, and number of
prefetch columns explicitly. For example:

```bash
make -C rtl/conv3x3 run-stream-column \
  CONFIG=ifn9 NUM_MULT=6 STREAM_COLUMN_PREFETCH_COLUMNS=3
```

The default dataset is the 3-input/3-output truncated package. Override
`STREAM_COLUMN_DATASET` when validating another channel workload. The
testbench is `rtl/stream-column/testbench_stream_column.sv` and compares each
output against the package golden data.

## ASIC synthesis and reports

The `synthesis/` directory is the canonical per-configuration location. See
[`synthesis/README.md`](synthesis/README.md) for flow layout and use
`make list-configs ARCH=conv3x3` to enumerate configs. Check the manifest and
stage evidence before treating a flow as complete.

Consolidated tables are in [`report/`](report/report.md); they are generated
from executed configurations under `synthesis/`. Historical reports and
variants under `archive/` are excluded by default.
