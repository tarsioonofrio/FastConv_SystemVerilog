# TCN9 Cin=3, Cout=12 frac6 dataset

Canonical workload: 32x32 input, Cin=3, Cout=12, 3x3 kernel, seed=0, NBITS=20 and QUANT_BITS=8. The scale-36 transformed weights retain six fractional bits with arithmetic-floor truncation.

This package is intended for the matching TCN9 pretransformed-frac6 RTL. `generation.json` records the source revision and package hash.
